# Sofy - 局域网隐秘通信解决方案

## 项目简介

**Sofy** 是一款专为局域网环境设计的隐秘通信与文件传输工具。它支持点对点（P2P）直连、群组聊天、文件同步以及堡垒机（Bastion Host）模式，旨在提供安全、便捷、高效的局域网协作体验。

Sofy 采用纯 Python 开发，无外部依赖，轻量级且易于部署。新增 GUI 界面，同时保留了强大的命令行功能，满足不同用户的需求。

## 核心功能

### 1. 通信模式

* **点对点 (P2P)**: 通过 Token 直接连接局域网内的其他用户，进行加密聊天和文件传输。
* **群组模式**: 创建或加入群组，支持群组广播、群成员列表查看、群内 P2P 私聊。
* **堡垒机模式**: 将一台设备设为 "Target" 堡垒机，自动管理群组 token，实现自动回复和流量中转引导。

### 2. 文件传输

* **自动同步**: 连接建立后，双方的 `Sync Folder` 自动同步。
* **拖拽互传**: 在 GUI 模式下，支持直接将文件拖拽发送给好友或群组。
* **断点续传**: 底层支持分块传输（基础实现）。

### 3. 用户界面

* **命令行 (CLI)**: 高效、纯文本交互，适合服务器或极客使用。
* **图形界面 (GUI)**:
  * 二次元/可爱风格主题 (｡♥‿♥｡)
  * link风格布局：好友/群组列表、聊天窗口、成员列表。
  * 右键菜单：快速查看 Token、发起连接、打招呼。
  * 功能按钮：一键生成 Token、查看本机 Token。

## 使用说明

### 启动方式

双击运行 `Sofy.exe` (Windows) 或在终端运行 `./Sofy` (Linux/Mac)。

启动后，程序会要求配置：

1. **Username**: 您的昵称。
2. **Password**: 连接密码（用于 P2P 验证）。
3. **Sync Folder**: 文件同步目录（默认为运行目录下的 `SofyData`）。
4. **Port**: 服务端口（默认 8888）。

配置完成后进入 `Sofy>` 命令行模式。

### 常用命令

* `ui`: **不推荐！** 启动图形化界面，有些功能缺失。
* `token`: 显示本机连接 Token。
* `gen`: 手动生成 Token（指定 IP/端口）。
* `connect <token>`: 连接到其他用户。
* `group creat <name>`: 创建群组。
* `group join <token>`: 加入群组。
* `list`: 列出当前连接和群组。
* `target be`: 切换到堡垒机模式（自动重启服务）。
* `help`: 查看完整命令列表。

### 堡垒机模式 (Bastion Mode)

用于局域网内的服务发现或中转引导。

1. 输入 `target be` 进入堡垒机模式。
2. 堡垒机自动创建名为 `target` 的群组。
3. 其他用户向堡垒机发送任意消息，堡垒机将自动回复 `target` 群组的 Token。

## 注意事项

* 请确保防火墙允许所选端口（默认 8888）的 TCP 通信。
* 文件同步会覆盖同名文件，请谨慎操作。
