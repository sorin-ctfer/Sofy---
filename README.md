# Sofy - 局域网隐秘通信解决方案

## 项目简介

**Sofy** 是一款专为局域网环境设计的隐秘通信与文件传输工具。它支持点对点（P2P）直连、群组聊天、文件同步以及堡垒机（Bastion Host）模式，旨在提供安全、便捷、高效的局域网协作体验。

Sofy 采用纯 Python 开发，无外部依赖，轻量级且易于部署。新增 GUI 界面，同时保留了强大的命令行功能，满足不同用户的需求。

## 快速开始

### 1. 启动软件

运行 `Sofy-dark-fix.exe`。首次启动时，你需要配置以下信息：

* **Username**: 你的昵称（用于标识身份）
* **Password**: 连接密码（用于身份验证）
* **Sync Folder**: 同步文件夹路径（默认为当前目录下的 `SofyData`，按回车使用默认）
* **Port**: 服务端口（默认为 `8888`，按回车使用默认）

启动成功后，屏幕上方会显示你的 **Token**（包含 IP、端口、用户名和密码的加密字符串）。

### 2. 基础命令

Sofy 使用命令行交互，支持以下核心指令：

* `token`：显示当前用户的连接 Token。
* `connect <Token>`：连接到另一个用户（需要对方的 Token）。
* `list`：列出当前所有活跃的连接和群组。
* `say "你好" to <User>`：给指定用户发送单条私信。
* `say into <User>`：进入与指定用户的**沉浸式聊天模式**（输入 `exit()` 退出）。
* `ui`：启动图形化界面（GUI），适合不习惯命令行的用户。
* `exit`：退出程序。

## 堡垒机模式与服务探测 (Service Discovery)

Sofy 提供独特的**堡垒机模式 (Bastion Mode)**，可将一台设备作为局域网内的“隐形枢纽”或“信标”，用于服务探测和自动组网。

### 使用场景

在局域网中，不知道其他人的 IP 和 Token，但希望快速建立连接并进入同一个群组。

### 操作步骤

**Step 1: 建立堡垒机 (Host)**
在作为枢纽的电脑上，输入命令：

```bash
target be
```

* 程序将切换到堡垒机模式，自动创建一个名为 `target` 的隐形群组。
* 屏幕会显示 `BASTION MODE ACTIVE`。

**Step 2: 服务探测与接入 (Client)**
其他用户只需知道堡垒机的 **IP 地址** 和默认端口 `8888`。

1. **生成连接 Token**：
   其他用户使用 `gen` 命令，手动生成指向堡垒机的 Token：

   * IP: 输入堡垒机的 IP
   * Username: `target` (固定)
   * Password: `target` (固定)
   * Port: `8888` (固定)
2. **连接堡垒机**：
   使用生成的 Token 进行连接：

   ```bash
   connect <生成的Token>
   ```
3. **触发自动应答**：
   连接成功后，尝试向 `target` 发送任意消息：

   ```bash
   say "hello" to target
   ```

   * **自动应答**：堡垒机会自动回复一条包含 `target` 群组 Token 的消息。
4. **加入群组**：
   复制回复中的 Group Token，执行：

   ```bash
   group join <GroupToken>
   ```

   现在，所有加入该群组的用户都可以互相通信和同步文件，实现了局域网内的自动发现与组网。

## Darkusing (隐匿/潜行模式)

这是 Sofy 最核心的隐秘特性。在该模式下，程序将完全从桌面环境中“消失”，仅在后台保留文件同步功能。

### 功能特点

* **界面消失**：命令行窗口、任务栏图标将全部隐藏。
* **静默运行**：后台进程继续保持与已连接群组的文件同步。
* **只读同步**：聊天功能将被禁用，仅保留定时文件同步（适合隐秘数据传输）。
* **防误触**：图形化界面无法唤出或关闭程序。

### 如何使用

1. **建立连接**：
   在进入隐匿模式前，先连接好需要同步的 Peer 或加入群组。
2. **进入模式**：
   输入命令：

   ```bash
   darkusing
   ```

   系统会提示确认：
   `Warning: This will hide the interface... Continue? (y/n):`
   输入 `y` 确认。
3. **潜行状态**：
   3秒后，终端窗口将自动关闭。此时 Sofy 仍在后台运行，每隔 2 秒自动同步文件夹内的文件。

### 如何退出

由于程序界面已完全隐藏，无法通过常规方式关闭。若要停止服务，需使用系统命令强制结束进程：

* **Windows**: 打开 CMD 或 PowerShell，执行 `taskkill /F /IM Sofy-dark-fix.exe`
* **Linux**: 打开终端，执行 `killall sofy-dark` 或 `pkill -f sofy`

## 📂 群组与文件同步

### 群组管理

* `group create <Name>`：创建一个新群组。
* `group join <Token>`：加入一个群组。
* `group into <Name>`：进入群组操作模式。

### 群组模式指令

进入群组模式后（`Sofy(groupname)>`）：

* `say into`：进入群组广播聊天模式。
* `list`：查看群组成员。
* `connect <User>`：与群内成员建立点对点（P2P）连接。

### 文件同步

Sofy 会自动监控设置的 `Sync Folder`。

* **自动上传**：将文件放入文件夹，会自动同步给所有已连接的 Peer/群组。
* **自动下载**：接收到的文件会自动出现在文件夹中。
* **同步删除**：**慎用！** 删除本地文件会同步指令，导致远程 Peer 的对应文件也被删除（支持防僵尸文件机制）。

### 1. 通信模式

* **点对点 (P2P)**: 通过 Token 直接连接局域网内的其他用户，进行加密聊天和文件传输。
* **群组模式**: 创建或加入群组，支持群组广播、群成员列表查看、群内 P2P 私聊。
* **堡垒机模式**: 将一台设备设为 "Target" 堡垒机，自动管理群组 token，实现自动回复和流量中转引导。

### 2. 文件传输

* **自动同步**: 连接建立后，双方的 `Sync Folder` 自动同步。
* **拖拽互传**: 在 GUI 模式下，支持直接将文件拖拽发送给好友或群组。
* **断点续传**: 底层支持分块传输（基础实现）。

### 3. 用户界面

* **命令行 (CLI)**: 高效、纯文本交互，适合服务器或极客使用。
* **图形界面 (GUI)**:
  * 二次元/可爱风格主题 (｡♥‿♥｡)
  * link风格布局：好友/群组列表、聊天窗口、成员列表。
  * 右键菜单：快速查看 Token、发起连接、打招呼。
  * 功能按钮：一键生成 Token、查看本机 Token。

## 使用说明

### 启动方式

双击运行 `Sofy.exe` (Windows) 或在终端运行 `./Sofy` (Linux/Mac)。

启动后，程序会要求配置：

1. **Username**: 您的昵称。
2. **Password**: 连接密码（用于 P2P 验证）。
3. **Sync Folder**: 文件同步目录（默认为运行目录下的 `SofyData`）。
4. **Port**: 服务端口（默认 8888）。

配置完成后进入 `Sofy>` 命令行模式。

### 常用命令

* `ui`: **不推荐！** 启动图形化界面，有些功能缺失。
* `token`: 显示本机连接 Token。
* `gen`: 手动生成 Token（指定 IP/端口）。
* `connect <token>`: 连接到其他用户。
* `group creat <name>`: 创建群组。
* `group join <token>`: 加入群组。
* `list`: 列出当前连接和群组。
* `target be`: 切换到堡垒机模式（自动重启服务）。
* `help`: 查看完整命令列表。
* **Windows**: 打开 CMD 或 PowerShell，执行 `taskkill /F /IM Sofy-dark-fix.exe`

### 堡垒机模式 (Bastion Mode)

用于局域网内的服务发现或中转引导。

1. 输入 `target be` 进入堡垒机模式。
2. 堡垒机自动创建名为 `target` 的群组。
3. 其他用户向堡垒机发送任意消息，堡垒机将自动回复 `target` 群组的 Token。

## 注意事项

* 请确保防火墙允许所选端口（默认 8888）的 TCP 通信。
* 文件同步会覆盖同名文件，请谨慎操作。
